# Grocery Platform Backend

Backend service for the grocery-store multi-tenant platform.

## Technology

- Python
- Django
- Django REST Framework
- PostgreSQL

## Local Development

The Docker-based development setup starts Django and PostgreSQL together. See [DOCKER_SETUP_INSTRUCTIONS.md](DOCKER_SETUP_INSTRUCTIONS.md) for startup commands, DBeaver connectivity, Postman setup, troubleshooting, and database reset warnings.

## Architecture

Modular monolith.

## Current Status

Project foundation only.

Business logic and domain implementation will be added incrementally.
